PRESS X TO JASON — Ethan Mars / Heavy Rain version

1. Put your MP3 or WAV files into the sounds folder.
2. Open script.js.
3. Add each filename to the `sounds` array, e.g.:

const sounds = [
  "sounds/jason-1.mp3",
  "sounds/jason-2.mp3",
  "sounds/jason-3.wav"
];

Open index.html in a browser.

Click the button or press X.
The same sound will not be selected twice consecutively.
